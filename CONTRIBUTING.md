# Contributing to Pablo Client

Thanks for helping. Please read `AGENTS.md` and `ROADMAP.md` first so your work fits the current phase.

- Branch from `main`, one branch per topic (`phaseN/<topic>` or `fix/<topic>`).
- Follow the performance rules in `ROADMAP.md`. State FPS with the client on and off in your pull request.
- Keep the code style of the surrounding files.
- Do not add features meant to evade anti-cheat, telemetry, or remote code execution.
- Add yourself to `CREDITS.md` if you contribute.
- Describe what your change does in the present tense in commit messages.
